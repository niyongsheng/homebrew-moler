# homebrew-moler

Homebrew tap for [Moler](https://github.com/niyongsheng/moler) — a NASA-Punk themed macOS disk cleaner.

## Install

```bash
brew tap niyongsheng/moler
brew install --cask moler
```

Or in one step:

```bash
brew install --cask niyongsheng/moler/moler
```

## Requirements

- macOS 14.0 (Sonoma) or later
- [Mole CLI](https://github.com/tw93/Mole) (`brew install mole`)
